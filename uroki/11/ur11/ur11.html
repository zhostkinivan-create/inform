Введение

В 11 классе мы подходим к завершению школьного курса информатики. За предыдущие годы вы изучили основы алгоритмизации, познакомились с несколькими языками программирования (Python, PascalABC.NET), научились работать с исполнителями и решать различные задачи.

Сегодня мы познакомимся с объектно-событийной моделью — современным подходом к созданию программ, который используется в большинстве профессиональных приложений.

📜 Историческая справка

Объектно-ориентированное программирование (ООП) зародилось в 1960-х годах с появлением языка Simula. Однако широкое распространение ООП получило в 1980-х с выходом языков C++ и Smalltalk. Сегодня ООП — доминирующая парадигма в разработке программного обеспечения.

Парадигмы программирования

Парадигма программирования — это совокупность идей и принципов, определяющих стиль написания программ.

📝 Процедурное программирование

  • Программа — это последовательность инструкций
  • Используются процедуры и функции
  • Данные и код разделены
  • Примеры: Pascal, C, Python (базовый уровень)

🧩 Объектно-ориентированное программирование

  • Программа — это набор объектов
  • Объекты содержат данные и методы
  • Данные и код объединены
  • Примеры: Java, C++, Python, PascalABC.NET

💡 Кроме ООП и процедурного программирования, существуют:

  • Функциональное программирование (Haskell, Lisp)
  • Логическое программирование (Prolog)
  • Аспектно-ориентированное программирование

Объектно-ориентированное программирование

Основные понятия ООП

📦 Объект

Это сущность, которая имеет состояние (данные) и поведение (методы). В реальном мире объектом может быть автомобиль, человек, кофеварка.

Пример: Объект «Автомобиль» имеет состояние (цвет, скорость, марка) и поведение (ехать, тормозить, поворачивать).

📐 Класс

Это шаблон (описание) для создания объектов. Класс определяет, какие данные и методы будут у объектов.

Пример: Класс «Автомобиль» описывает, что у любого автомобиля есть цвет, скорость и методы движения.

🔒 Инкапсуляция

Это сокрытие внутреннего состояния объекта от внешнего мира. Доступ к данным осуществляется через методы.

Пример: Вы не можете напрямую изменить скорость автомобиля — вы используете педаль газа (метод).

🧬 Наследование

Это возможность создавать новые классы на основе существующих, добавляя или изменяя их свойства.

Пример: Класс «Электромобиль» наследует свойства класса «Автомобиль» и добавляет новые (ёмкость батареи).

🎭 Полиморфизм

Это возможность использовать объекты разных классов через единый интерфейс.

Пример: Метод «ехать» работает и для бензинового автомобиля, и для электромобиля, но реализован по-разному.

Событийная модель

Что такое событие?

Событие — это действие, которое происходит в программе (нажатие кнопки, движение мыши, загрузка страницы).

Событийная модель — это подход, при котором программа реагирует на события, а не просто выполняет последовательность команд.

📋 Линейная программа

  • Программа выполняется от начала до конца
  • Порядок действий фиксирован
  • Пользователь не может повлиять на ход выполнения
  • Пример: Консольное приложение

🔄 Событийная программа

  • Программа ждёт событий
  • Реагирует на действия пользователя
  • Порядок действий определяется пользователем
  • Пример: Графическое приложение

Объектно-событийная модель

В объектно-событийной модели объекты генерируют события, а другие объекты могут на них реагировать (обработчики событий).

Пример работы событийной модели:

  1. Пользователь нажимает кнопку на форме (событие)
  2. Программа определяет, какая кнопка была нажата
  3. Вызывается обработчик события для этой кнопки
  4. Обработчик выполняет нужные действия

🖥️ Где используется событийная модель?

  • Графические интерфейсы пользователя (GUI)
  • Веб-приложения (клики, скролл, ввод текста)
  • Мобильные приложения
  • Игры
  • Операционные системы

Визуальные среды разработки

Визуальная среда разработки (Visual IDE) — это инструмент, который позволяет создавать программы, используя графические элементы, а не только код.

🖱️ Конструктор интерфейса

Позволяет перетаскивать элементы управления (кнопки, поля, списки) на форму и располагать их визуально.

📋 Инспектор объектов

Показывает свойства выбранного элемента и позволяет их изменять без написания кода.

⚡ Генерация кода

Среда автоматически создаёт код для визуальных элементов, который затем можно дополнить логикой.

💻 Примеры визуальных сред:

  • PascalABC.NET — встроенная среда для создания Windows-приложений
  • Visual Studio (C#, C++)
  • Delphi (Object Pascal)
  • Qt Designer (C++, Python)
  • Android Studio (мобильные приложения)

Примеры на PascalABC.NET

Пример 1. Простое оконное приложение

program HelloForm;
uses System.Windows.Forms;

var
  form: Form;
  button: Button;

begin
  form := Form.Create;
  form.Text := 'Привет, мир!';
  form.Size := System.Drawing.Size.Create(300, 200);
  
  button := Button.Create;
  button.Text := 'Нажми меня!';
  button.Location := System.Drawing.Point.Create(100, 80);
  button.Size := System.Drawing.Size.Create(100, 30);
  
  form.Controls.Add(button);
  Application.Run(form);
end.

В этом примере создаются объекты form (форма) и button (кнопка), которые затем отображаются на экране.

Пример 2. Обработка события

program ButtonClick;
uses System.Windows.Forms;

var
  form: Form;
  button: Button;

procedure OnButtonClick(sender: object; e: EventArgs);
begin
  MessageBox.Show('Вы нажали кнопку!');
end;

begin
  form := Form.Create;
  form.Text := 'Событие';
  
  button := Button.Create;
  button.Text := 'Нажми';
  button.Location := System.Drawing.Point.Create(100, 80);
  button.Click += OnButtonClick;  // Подключение обработчика
  
  form.Controls.Add(button);
  Application.Run(form);
end.

Здесь метод OnButtonClick будет вызван, когда пользователь нажмёт на кнопку.

Пример 3. Визуальный конструктор

В среде PascalABC.NET можно создавать формы визуально, не написав ни строчки кода. Затем можно добавить обработчики событий для элементов.

Этапы создания приложения в визуальной среде:

  1. Создать новый проект «Windows Forms Application»
  2. Перетащить элементы управления на форму
  3. Настроить свойства элементов (текст, размер, цвет)
  4. Дважды щёлкнуть по элементу для создания обработчика
  5. Написать код в обработчике события
  6. Запустить приложение
