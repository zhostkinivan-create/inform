Основные алгоритмические конструкции

Что такое алгоритмическая конструкция?

Алгоритмическая конструкция — это базовый блок, из которого строится любой алгоритм. Все алгоритмы можно составить из трёх основных конструкций:

  • Следование — команды выполняются последовательно, одна за другой
  • Ветвление — выбор одного из двух путей в зависимости от условия
  • Повторение (цикл) — многократное выполнение команд

📜 Историческая справка

В 1966 году итальянские учёные Коррадо Бём и Джузеппе Якопини доказали, что любой алгоритм можно записать, используя только эти три конструкции. Это открытие стало фундаментом структурного программирования.

1. Следование (линейный алгоритм)

Следование — это конструкция, при которой команды выполняются в порядке их записи. Никаких условий и повторений нет.

Пример на Python (исполнитель Черепаха из 6 класса):

import turtle
turtle.forward(100)   # 1 шаг
turtle.left(90)       # 2 шаг
turtle.forward(50)    # 3 шаг

Здесь команды выполняются строго по порядку — это следование.

2. Ветвление (условный алгоритм)

Ветвление — это конструкция, которая позволяет выбрать один из двух путей выполнения в зависимости от условия.

В Python ветвление записывается с помощью оператора if:

Пример (из 7 класса, исполнитель Робот):

temperature = int(input("Введите температуру: "))
if temperature > 0:
    print("На улице тепло")
else:
    print("На улице холодно")

Если температура больше 0 — выполняется один блок, иначе — другой.

3. Повторение (циклы)

Повторение (цикл) — это конструкция, которая позволяет многократно выполнять команды.

В Python есть два основных типа циклов:

  • Цикл с предусловием while — выполняется, пока условие истинно
  • Цикл с параметром for — выполняется заданное количество раз

Пример на Python (while):

count = 0
while count < 5:
    print("Привет!")
    count = count + 1

Цикл выполнится 5 раз, пока count меньше 5.

Пример на Python (for):

for i in range(5):
    print(f"Шаг номер {i+1}")

Цикл выполнится 5 раз (от 0 до 4).

Комбинирование конструкций

В реальных алгоритмах конструкции вкладываются друг в друга. Например, внутри цикла может быть ветвление, а внутри ветвления — ещё один цикл.

Пример (вложенные конструкции):

for i in range(10):          # внешний цикл
    if i % 2 == 0:           # ветвление внутри цикла
        print(f"{i} - чётное")
    else:
        print(f"{i} - нечётное")

Здесь цикл for содержит внутри себя ветвление if.

💡 Интересный факт

Любой алгоритм можно записать с помощью этих трёх конструкций. Программисты называют это «структурной теоремой». Она позволяет писать понятный и легко читаемый код.

Примеры решения задач

Задача 1 (следование)

Условие: Напишите программу, которая запрашивает у пользователя два числа и выводит их сумму.

Решение:

a = int(input("Введите первое число: "))
b = int(input("Введите второе число: "))
summa = a + b
print("Сумма чисел:", summa)

Это линейный алгоритм — команды выполняются последовательно.

Задача 2 (ветвление)

Условие: Напишите программу, которая проверяет, является ли число чётным.

Решение:

number = int(input("Введите число: "))
if number % 2 == 0:
    print("Число чётное")
else:
    print("Число нечётное")

Здесь используется конструкция ветвления if-else.

Задача 3 (цикл for)

Условие: Напишите программу, которая выводит все числа от 1 до 10.

Решение:

for i in range(1, 11):
    print(i)

Цикл for выполняется 10 раз.

Задача 4 (цикл while)

Условие: Напишите программу, которая запрашивает числа, пока пользователь не введёт 0.

Решение:

number = 1
while number != 0:
    number = int(input("Введите число (0 для выхода): "))
    if number != 0:
        print("Вы ввели:", number)
print("Программа завершена")

Цикл while выполняется, пока number не станет равным 0.

Задача 5 (вложенные конструкции)

Условие: Напишите программу, которая выводит таблицу умножения на число, введённое пользователем.

Решение:

n = int(input("Введите число: "))
for i in range(1, 11):
    print(f"{n} × {i} = {n * i}")

Здесь цикл for с вложенным выводом.
