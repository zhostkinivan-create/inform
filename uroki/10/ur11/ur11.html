Введение

В 10 классе мы переходим к более серьёзному изучению программирования. Вы уже знакомы с основами алгоритмизации, работали с исполнителями (Черепаха, Робот) и изучали Python. Теперь мы познакомимся с языком PascalABC.NET — мощным инструментом для решения учебных и практических задач.

На этом уроке мы разберемся, что такое алгоритм, какими свойствами он обладает, и как алгоритмы превращаются в программы на языках программирования.

📜 Историческая справка

Слово «алгоритм» происходит от имени великого средневекового математика Мухаммеда ибн Мусы аль-Хорезми (ок. 783–850). Он жил в Багдаде и написал книгу «О сложении и вычитании», где описал правила выполнения арифметических действий. Его имя в латинской транскрипции — Algorithmi — дало название понятию «алгоритм».

Понятие алгоритма

Что такое алгоритм?

Алгоритм — это понятная, конечная последовательность точных команд, формальное выполнение которых позволяет получить результат.

Примеры алгоритмов из жизни:

  • Рецепт приготовления блюда — последовательность действий для получения результата
  • Инструкция по сборке мебели — чёткие шаги, которые нужно выполнить
  • Правила перехода дороги: остановиться, посмотреть налево, направо, затем перейти

Исполнитель алгоритма

Исполнитель — это субъект (человек или устройство), который может понять и выполнить команды алгоритма.

  • Человек — может выполнять алгоритмы, следуя инструкциям
  • Компьютер — главный исполнитель алгоритмов в информатике
  • Робот — техническое устройство, выполняющее алгоритмы

💡 Важно!

Алгоритм должен быть записан на языке, который понимает исполнитель. Для компьютера это язык программирования, для человека — естественный язык (русский, белорусский и т.д.)

Свойства алгоритмов

Любой алгоритм должен обладать следующими свойствами:

1️⃣ Дискретность

Алгоритм состоит из отдельных шагов (команд), которые выполняются последовательно. Каждый шаг должен быть чётко определён.

Пример: Инструкция «Помыть руки»:
1. Открыть кран
2. Намочить руки
3. Нанести мыло
4. Смыть мыло
5. Закрыть кран

2️⃣ Определённость (Детерминированность)

Каждая команда должна быть однозначно понята исполнителем. Не должно быть двусмысленности.

Пример: Плохой алгоритм: «Добавить немного соли».
Хороший алгоритм: «Добавить 5 граммов соли».

3️⃣ Результативность

Алгоритм должен обязательно привести к результату за конечное число шагов.

Пример: Алгоритм вычисления суммы чисел всегда даёт результат.

4️⃣ Массовость

Алгоритм должен быть применим к целому классу задач, а не только к одной конкретной.

Пример: Алгоритм сложения двух чисел работает для любых чисел, а не только для 2+2.

5️⃣ Понятность

Алгоритм должен быть записан на языке, понятном исполнителю.

Пример: Для компьютера алгоритм должен быть записан на языке программирования, а для человека — на естественном языке.

Языки программирования

Что такое язык программирования?

Язык программирования — это формальный язык, предназначенный для записи алгоритмов в виде, понятном компьютеру.

Существует множество языков программирования. Их можно классифицировать по разным признакам:

📊 По уровню

  • Низкого уровня (машинные коды, ассемблер) — близки к процессору
  • Высокого уровня (Pascal, Python, Java) — близки к человеческому языку

🎯 По назначению

  • Универсальные (Pascal, C++) — для любых задач
  • Специализированные (SQL, HTML) — для конкретных областей

Поколения языков программирования

  • 1 поколение (1940-1950) — машинные коды (0 и 1)
  • 2 поколение (1950-1960) — ассемблер (символьные обозначения)
  • 3 поколение (1960-1980) — языки высокого уровня (Fortran, Pascal, C)
  • 4 поколение (1980-1990) — языки для работы с базами данных (SQL)
  • 5 поколение (1990-…) — языки искусственного интеллекта (Prolog, Lisp)

💡 Интересный факт

Первый язык программирования высокого уровня — Plankalkül — был разработан в 1940-х годах Конрадом Цузе, но не был реализован. Первым реализованным языком считается Fortran (1957 год).

PascalABC.NET

История Pascal

Язык Pascal был создан в 1970 году швейцарским учёным Никлаусом Виртом. Он назвал его в честь французского математика и философа Блеза Паскаля.

PascalABC.NET — это современная версия языка Pascal, разработанная в России. Она сочетает классический синтаксис Pascal с возможностями платформы .NET.

✨ Особенности PascalABC.NET:

  • Бесплатный и простой в использовании
  • Встроенная среда разработки (IDE)
  • Поддержка объектно-ориентированного программирования
  • Мощная стандартная библиотека
  • Отличный выбор для обучения программированию

Структура программы на Pascal

Базовая структура:

program HelloWorld;      // Заголовок программы
uses crt;                // Подключение модулей
var                      // Описание переменных
  a, b: integer;
begin                    // Начало программы
  writeln('Hello, World!');  // Вывод на экран
end.                     // Конец программы
  • program — заголовок программы (можно опускать)
  • uses — подключение дополнительных модулей
  • var — раздел описания переменных
  • begin — начало выполнения программы
  • end. — конец программы (точка обязательна)

Примеры программ на PascalABC.NET

Пример 1. Вывод на экран

program Hello;
begin
  writeln('Привет, мир!');
  writeln('Это моя первая программа');
end.

Команда writeln выводит текст на экран и переводит курсор на новую строку.

Пример 2. Сложение двух чисел

program Sum;
var
  a, b, c: integer;
begin
  write('Введите первое число: ');
  readln(a);
  write('Введите второе число: ');
  readln(b);
  c := a + b;
  writeln('Сумма чисел: ', c);
end.
  • write — вывод без перевода строки
  • readln — ввод значения с клавиатуры
  • := — оператор присваивания

Пример 3. Ветвление (if)

program CheckNumber;
var
  number: integer;
begin
  write('Введите число: ');
  readln(number);
  if number > 0 then
    writeln('Число положительное')
  else if number < 0 then
    writeln('Число отрицательное')
  else
    writeln('Число равно нулю');
end.

Конструкция if-else позволяет выполнять разные действия в зависимости от условия.

Пример 4. Цикл (for)

program CountTo10;
var
  i: integer;
begin
  for i := 1 to 10 do
    writeln('Шаг номер ', i);
end.

Цикл for выполняется заданное количество раз.
