Что такое Интернет?

Интернет (от англ. Interconnected Networks — объединённые сети) — это всемирная компьютерная сеть, объединяющая миллионы компьютеров и устройств по всему миру.

Интернет работает благодаря сте́ковой протоколов TCP/IP — набору правил, которые определяют, как данные передаются между устройствами в сети.

📜 Историческая справка

Прообразом современного Интернета стала сеть ARPANET, созданная в 1969 году в США. Первое сообщение было отправлено между компьютерами в Калифорнийском и Стэнфордском университетах. Тогда сеть объединяла всего 4 компьютера!

🌍 Интернет сегодня

По состоянию на 2025 год более 5,5 миллиардов человек (около 67% населения Земли) являются пользователями Интернета. Количество подключённых устройств превышает 30 миллиардов.

IP-адреса

Что такое IP-адрес?

IP-адрес (Internet Protocol Address) — это уникальный числовой идентификатор устройства в сети Интернет. По аналогии с почтовым адресом: чтобы отправить письмо, нужно знать адрес получателя. Так и в сети: чтобы передать данные, нужно знать IP-адрес устройства.

Пример IP-адреса:

192.168.1.1 — это IP-адрес, состоящий из 4 чисел, разделённых точками.

Двоичное представление IP-адреса

На самом деле IP-адрес — это 32-битное двоичное число. Для удобства его разделяют на 4 октета (по 8 бит) и записывают в десятичном виде.

Пример преобразования:

IP-адрес 192.168.1.1 в двоичном виде:

192 = 11000000
168 = 10101000
1   = 00000001
1   = 00000001

Итог: 11000000.10101000.00000001.00000001

💡 Интересный факт

Всего существует 2³² = 4 294 967 296 возможных IPv4-адресов. Кажется, что это много, но из-за роста числа устройств в мире адресов стало не хватать. Поэтому был создан стандарт IPv6 с 128-битными адресами, которых хватит на всех!

Динамические и статические IP-адреса

🔄 Динамический IP

  • Меняется при каждом подключении к сети
  • Используется у большинства домашних пользователей
  • Назначается автоматически (DHCP-сервером)
  • Экономит адресное пространство

📌 Статический IP

  • Всегда остаётся неизменным
  • Используется для серверов, хостингов
  • Назначается вручную
  • Нужен для постоянного доступа к устройству

Пример из жизни

Ваш домашний компьютер чаще всего получает динамический IP-адрес от провайдера. А веб-сайт Google имеет статический IP-адрес, чтобы пользователи всегда могли к нему обратиться.

Протоколы TCP/IP

Что такое протокол?

Протокол — это набор правил и стандартов, определяющих, как данные передаются по сети. Представьте, что это язык, на котором устройства общаются друг с другом.

Модель TCP/IP

Стек протоколов TCP/IP включает несколько уровней. Основные протоколы:

  • IP (Internet Protocol) — отвечает за доставку данных (маршрутизацию)
  • TCP (Transmission Control Protocol) — обеспечивает надёжную передачу данных с проверкой доставки
  • UDP (User Datagram Protocol) — быстрая передача без проверки доставки (для видео, аудио)

🔍 Как работает TCP?

TCP разбивает данные на маленькие пакеты, отправляет их по сети, а затем собирает в правильном порядке. Если какой-то пакет потерялся — TCP запрашивает его повторную отправку. Это как отправка книги по частям с проверкой, что все страницы дошли.

Протоколы прикладного уровня

Над TCP/IP работают протоколы, которые мы используем каждый день:

  • HTTP (HyperText Transfer Protocol) — передача веб-страниц
  • HTTPS (HTTP Secure) — защищённая версия HTTP
  • FTP (File Transfer Protocol) — передача файлов
  • SMTP (Simple Mail Transfer Protocol) — отправка почты
  • DNS (Domain Name System) — преобразование доменных имён в IP-адреса

HTTP и HTTPS

HTTP (HyperText Transfer Protocol)

HTTP — это протокол, по которому веб-браузеры получают веб-страницы от серверов. Когда вы вводите адрес сайта, браузер отправляет HTTP-запрос, а сервер возвращает HTML-страницу.

Как работает HTTP:

  1. Вы вводите http://example.com
  2. Браузер отправляет HTTP-запрос на сервер
  3. Сервер обрабатывает запрос и отправляет ответ (HTML-страницу)
  4. Браузер отображает страницу

HTTPS (HyperText Transfer Protocol Secure)

HTTPS — это защищённая версия HTTP. Все данные между браузером и сервером шифруются. Это защищает информацию от перехвата злоумышленниками.

🔓 HTTP (небезопасный)

  • Данные передаются в открытом виде
  • Информация может быть перехвачена
  • Используется на старых сайтах
  • Адрес начинается с http://

🔒 HTTPS (безопасный)

  • Данные шифруются
  • Информация защищена от перехвата
  • Используется на всех современных сайтах
  • Адрес начинается с https://

🛡️ Важно знать

Сегодня все крупные сайты используют HTTPS. Браузеры помечают сайты без HTTPS как «Небезопасные». Это делается для защиты ваших паролей, данных банковских карт и личной информации.

DNS и MAC-адреса

DNS (Domain Name System)

DNS — это «телефонная книга» Интернета. Он преобразует понятные человеку доменные имена (например, google.com) в числовые IP-адреса, понятные компьютерам.

Как работает DNS:

  1. Вы вводите google.com в браузере
  2. Браузер обращается к DNS-серверу
  3. DNS-сервер возвращает IP-адрес: 142.250.185.78
  4. Браузер подключается к этому IP-адресу

💡 Интересный факт

Самый первый домен symbolics.com был зарегистрирован в 1985 году. Сегодня в мире существует более 300 миллионов зарегистрированных доменов.

MAC-адреса

MAC-адрес (Media Access Control) — это уникальный физический адрес сетевого устройства (например, сетевой карты). В отличие от IP-адреса, MAC-адрес «прошит» в устройстве на заводе и не меняется.

IP-адрес

  • Логический адрес (может меняться)
  • Состоит из 4 чисел (IPv4)
  • Определяет место устройства в сети
  • Пример: 192.168.1.1

MAC-адрес

  • Физический адрес (не меняется)
  • Состоит из 6 байт в шестнадцатеричном виде
  • Уникален для каждого устройства
  • Пример: 00:1A:2B:3C:4D:5E

Как они работают вместе:

  1. Устройство имеет MAC-адрес (физический «паспорт»)
  2. В сети оно получает IP-адрес («временная прописка»)
  3. Маршрутизаторы используют IP для доставки данных
  4. Внутри локальной сети данные передаются по MAC-адресам
